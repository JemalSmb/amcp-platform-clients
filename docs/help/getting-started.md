# Getting Started With The Dashboard

The AMCP dashboard is organized by domain and operational surface.

## Primary Views

- Home: domain health and 24h event volume.
- Alerts: event stream with severity and source context.
- Predictions: latest model inference outputs.
- Reports: scheduled and on-demand summaries.

## Recommended Daily Flow

1. Open Home and confirm all active domains are operational.
2. Review high and critical alerts.
3. Validate model status before responding to anomalies.
4. Track remediation in incidents and investigations.

## Response Priority

- Critical: act immediately and escalate.
- High: investigate within the current shift.
- Medium: triage and queue.
- Low: monitor and bundle for periodic review.
